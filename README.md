Maslov - Raytracing functions written in Fortran77 and Fortran90



These Fortran-codes were mostly written when I was a PhD student, and visiting scholar at Center for Wave Phenomena, Colorado School of Mines, in 1998-1999. The ray tracing was the core of a method to compute Maslov Green's functions, see the paper from SIAM 2001 in the docs folder. 



I don't know if it's still possible to compute Maslov asymptotics with the code. However, there's a working example computing heat conduction in the coldrays folder. This example demonstrates that it's possible to compute heat conduction with a seismic ray tracer, because the mathematical equivalence of the Eikonal equation and Fourier's law.
